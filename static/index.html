你未安装 mihomo

    
本面板依赖 mihomo 内核，请先自行安装 mihomo，安装成功后才能登录使用。

    

      🔗 打开 mihomo 下载页（GitHub Releases）
    

    

      
📌 安装步骤

      
    
        
  1. 在下载页选择与自己 CPU 匹配的 .deb 安装包（注意 GOAMD64 档位）
    2. 
        
  2. 下载后在终端执行：sudo apt install ./下载的包.deb（或 sudo dpkg -i 下载的包.deb），或直接用下方「上传安装」
    3. 
        
  3. 安装完成后点击下方「重新检测」，通过后自动释放 metacubexd 面板并开放登录
    4. 
      

      

        v3 · 2013 年后的普通 PC / 笔记本（Intel 4 代后、AMD 锐龙），需 AVX2

        v2 · 2008~2013 年老电脑、老服务器，需 SSE4.2 / POPCNT

        v1 · 很老的 CPU（J1900、G1840、初代至强等），任意 x86-64，最稳
